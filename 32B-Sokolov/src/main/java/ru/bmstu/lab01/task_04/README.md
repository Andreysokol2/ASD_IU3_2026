# Задача 4. Все индексы элемента

## Решение
Прохожу массив и добавляю подходящие индексы в `ArrayList`. Индексы идут по возрастанию сами, потому что i растёт. Список взял, потому что заранее неизвестно сколько будет совпадений.

## Асимптотика

```java
List<Integer> res = new ArrayList<>();   // 1 раз
for (int i = 0; i < a.length; i++) {     // n итераций
    if (a[i] == x) {                      // n раз
        res.add(i);                       // k раз, O(1) амортизированно
    }
}
```

`add` иногда расширяет внутренний массив (копирование), но в сумме на k добавлений это O(k).

T(n) = n + O(k), k ≤ n → **O(n)**

Память: список из k индексов, в худшем случае k = n → **O(n)**.

## Тесты
- несколько вхождений, проверка порядка;
- элемента нет → пустой список;
- вывод `main`.
