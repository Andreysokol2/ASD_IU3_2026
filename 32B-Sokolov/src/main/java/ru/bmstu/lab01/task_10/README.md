# Задача 10. Последний элемент, кратный k

## Решение
Иду с конца, первый найденный кратный и есть последний. Для отрицательных чисел `%` в Java может дать отрицательный остаток, но 0 всё равно 0, так что проверка работает при любых знаках. На 0 не делим, т.к. по условию k ≠ 0.

## Асимптотика

```java
for (int i = a.length - 1; i >= 0; i--) {   // до n итераций
    if (a[i] % k == 0) {                     // 1 деление + сравнение
        return i;
    }
}
return -1;
```

- худший случай (кратных нет): n проверок → **O(n)**;
- лучший (последний кратен): O(1).

Память: **O(1)**.

## Тесты
- несколько кратных (нужен последний);
- кратных нет → -1;
- отрицательные числа, отрицательное k и ноль;
- вывод `main`.
