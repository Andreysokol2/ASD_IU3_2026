# Задача 6. Элементы больше среднего

## Решение
Сначала считаю сумму и среднее, потом вторым проходом считаю элементы больше среднего. За один проход не получится — среднее известно только в конце.

## Асимптотика

```java
long sum = 0;
for (int v : a) {             // 1-й проход: n итераций
    sum += v;
}
long avg = sum / a.length;    // 1 раз

int cnt = 0;
for (int v : a) {             // 2-й проход: n итераций
    if (v > avg) {
        cnt++;
    }
}
```

T(n) = n + n + const = 2n → **O(n)**

Память: `sum`, `avg`, `cnt` → **O(1)**.

## Тесты
- обычный случай (`1 2 3 4 5`, среднее 3);
- все равны → 0 (сравнение строгое);
- отрицательное среднее;
- вывод `main`.
