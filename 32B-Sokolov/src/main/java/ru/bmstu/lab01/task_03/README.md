# Задача 3. Подсчёт вхождений

## Решение
Прохожу весь массив и увеличиваю счётчик. Раньше выйти нельзя — совпадение может быть в конце.

## Асимптотика

```java
int cnt = 0;              // 1 раз
for (int v : a) {         // n итераций
    if (v == x) {         // n раз
        cnt++;
    }
}
```

T(n) = 1 + n → **O(n)**

Память: `cnt` → **O(1)**.

## Тесты
- несколько вхождений;
- ни одного → 0;
- вывод `main`.
