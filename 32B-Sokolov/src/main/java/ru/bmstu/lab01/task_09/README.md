# Задача 9. Проверка отсортированности

## Решение
Сравниваю соседей: если где-то `a[i] < a[i - 1]`, массив не неубывающий. Равные соседи — нормально.

## Асимптотика

```java
for (int i = 1; i < a.length; i++) {   // до n-1 итераций
    if (a[i] < a[i - 1]) {               // 1 сравнение
        return false;
    }
}
return true;
```

- худший случай (массив отсортирован): n-1 сравнений → **O(n)**;
- лучший (нарушение в начале): O(1).

Память: **O(1)**.

## Тесты
- равные соседи → YES;
- нарушение в самом конце → NO;
- вывод `main` для YES и для NO.
