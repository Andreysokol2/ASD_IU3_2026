# Задача 1. Максимум и минимум

## Решение
Один проход по массиву, `min` и `max` сначала равны первому элементу.

## Асимптотика

```java
int min = a[0];                          // 1 раз
int max = a[0];                          // 1 раз
for (int i = 1; i < a.length; i++) {     // n-1 итераций
    if (a[i] < min) {                    // n-1 раз
        min = a[i];
    }
    if (a[i] > max) {                    // n-1 раз
        max = a[i];
    }
}
```

T(n) = 2 + 2(n-1) = 2n → **O(n)**

Быстрее нельзя: любой элемент может быть минимумом или максимумом, значит каждый надо посмотреть.

Память: только `min` и `max` → **O(1)**.

## Тесты
- обычный массив;
- все элементы одинаковые;
- `Integer.MIN_VALUE` и `Integer.MAX_VALUE` в массиве;
- вывод `main`.
