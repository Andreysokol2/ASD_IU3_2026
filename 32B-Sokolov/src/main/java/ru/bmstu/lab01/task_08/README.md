# Задача 8. Фильтрация по знаку

## Решение
Два метода: `positives` собирает положительные, `negatives` — отрицательные. Иду слева направо, так что порядок сохраняется. Нули не подходят ни под `> 0`, ни под `< 0`, поэтому выкидываются сами.

## Асимптотика

```java
// positives
for (int v : a) {        // n итераций
    if (v > 0) {
        res.add(v);      // O(1) амортизированно
    }
}

// negatives
for (int v : a) {        // ещё n итераций
    if (v < 0) {
        res.add(v);
    }
}
```

T(n) = n + n = 2n → **O(n)**

Память: в двух списках p + q элементов, p + q ≤ n → **O(n)**.

## Тесты
- смешанный массив с нулями (порядок и отсутствие нулей);
- только нули → оба списка пустые;
- вывод `main`.
