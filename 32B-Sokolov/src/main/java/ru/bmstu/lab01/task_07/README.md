# Задача 7. Второй максимум

## Решение
Можно отсортировать и взять предпоследний, но это O(n log n). Делаю за один проход с двумя переменными. Начинаю с первых двух элементов, а не с `Integer.MIN_VALUE`, потому что он может оказаться в массиве.

## Асимптотика

```java
int max = Math.max(a[0], a[1]);          // 1 раз
int second = Math.min(a[0], a[1]);       // 1 раз
for (int i = 2; i < a.length; i++) {     // n-2 итераций
    if (a[i] > max) {                     // ≤ 2 сравнения за итерацию
        second = max;
        max = a[i];
    } else if (a[i] > second) {
        second = a[i];
    }
}
```

T(n) ≤ 2 + 2(n-2) → **O(n)**

Память: **O(1)**.

## Тесты
- обычный массив;
- возрастающий массив (max меняется на каждом шаге и старый уходит во второй);
- два элемента;
- вывод `main`.
