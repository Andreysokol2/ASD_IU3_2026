# Задача 11. Ближайший к среднему

## Решение
Сумма в `long`, среднее в `double`, т.к. оно может быть дробным. Потом ищу элемент с наименьшим `|a[i] - avg|`. Сравнение строгое, поэтому при одинаковом расстоянии остаётся тот, что раньше.

## Асимптотика

```java
long sum = 0;
for (int v : a) {                                         // n итераций
    sum += v;
}
double avg = (double) sum / a.length;                     // 1 раз

int best = a[0];
for (int i = 1; i < a.length; i++) {                      // n-1 итераций
    if (Math.abs(a[i] - avg) < Math.abs(best - avg)) {    // O(1)
        best = a[i];
    }
}
```

T(n) = n + (n-1) + const → **O(n)**

Память: **O(1)**.

## Тесты
- дробное среднее (7/3);
- два элемента на одинаковом расстоянии от 2.5 → берётся первый;
- отрицательное среднее;
- вывод `main`.
