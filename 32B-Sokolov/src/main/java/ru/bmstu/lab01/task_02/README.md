# Задача 2. Индекс первого вхождения

## Решение
Иду слева направо, при первом совпадении возвращаю индекс. Массив не отсортирован, поэтому бинарный поиск не подходит.

## Асимптотика

```java
for (int i = 0; i < a.length; i++) {    // до n итераций
    if (a[i] == x) {                     // 1 сравнение
        return i;
    }
}
return -1;
```

- худший случай (x нет или он последний): n сравнений → **O(n)**;
- лучший случай (`a[0] == x`): 1 сравнение → O(1).

Память: **O(1)**.

## Тесты
- несколько вхождений (должен вернуться первый);
- элемента нет → -1;
- элемент последний;
- вывод `main`.
