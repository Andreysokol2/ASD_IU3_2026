# Задача 5. Сумма на чётных позициях

## Решение
Цикл с шагом 2 от нуля, тогда проверять `i % 2` не нужно. Сумма в `long`, потому что сумма многих int может не влезть в int.

## Асимптотика

```java
long sum = 0;                              // 1 раз
for (int i = 0; i < a.length; i += 2) {    // ⌈n/2⌉ итераций
    sum += a[i];                           // ⌈n/2⌉ раз
}
```

T(n) = 1 + ⌈n/2⌉ ≈ n/2 → **O(n)** (константа 1/2 не влияет)

Память: **O(1)**.

## Тесты
- длина нечётная и чётная (последний элемент берётся / не берётся);
- три `Integer.MAX_VALUE` — проверка, что нет переполнения;
- вывод `main`.
