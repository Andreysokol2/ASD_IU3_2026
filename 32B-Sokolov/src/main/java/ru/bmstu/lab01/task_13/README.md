# Задача 13. Сортировка выбором

## Решение
На шаге i ищу минимум в части `[i, n)` и меняю его местами с `a[i]`. После шага i элементы `[0, i]` уже на своих местах. Сортирую на месте, встроенные сортировки не использую.

## Асимптотика

```java
for (int i = 0; i < a.length - 1; i++) {      // n-1 итераций
    int minIdx = i;
    for (int j = i + 1; j < a.length; j++) {  // n-1-i итераций
        if (a[j] < a[minIdx]) {               // 1 сравнение
            minIdx = j;
        }
    }
    int tmp = a[i];                           // обмен: n-1 раз всего
    a[i] = a[minIdx];
    a[minIdx] = tmp;
}
```

Сравнений во внутреннем цикле:

(n-1) + (n-2) + ... + 1 = n(n-1)/2

T(n) = n(n-1)/2 + 3(n-1) → **O(n²)**

Это в любом случае, даже для уже отсортированного массива: внутренний цикл всегда проходит до конца.

Память: только `minIdx` и `tmp` → **O(1)**.

## Тесты
- обычный массив с отрицательными;
- массив с повторами;
- уже отсортированный массив не портится;
- вывод `main`.
