# Отчёт по ЛР 1

ФИО: Соколов Андрей Павлович
Группа: ИУ3-32Б

Сделаны задачи 1–12 (по 1 баллу) и задача 13 (2 балла), всего 14 баллов.

## Как устроено

Каждая задача в своём пакете `task_NN`: класс `TaskNN` с методом-решением и `main`, который читает ввод и печатает ответ.
Чтение массива вынесено в `util/ArrayIO`, чтобы не повторять его в каждой задаче.
Формат ввода: n, потом n чисел, потом x / k / s если нужно.

Подробное решение и расчёт асимптотики — в `README.md` в папке каждой задачи.

| 7. Второй максимум | O(n) | O(1) |
| 8. Фильтр по знаку | O(n) | O(n) |

## Тесты

Для каждой задачи обычный случай, граничные случаи (элемента нет, все равны, переполнение и т.п.) и проверка вывода `main` через подмену `System.in`/`System.out` (`util/TestUtils`).
Покрытие по JaCoCo больше 80%, отчёт после `mvn clean test` в `target/site/jacoco/index.html`.
